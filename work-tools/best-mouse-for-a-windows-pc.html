Check one: the receiver and the ports — on Windows, the receiver plugs straight in

Start with the port, because on Windows this check runs backwards from the Mac version. All four mice here include a USB-A receiver in the box: a Logi Bolt receiver with the MX Master 3S, the Lift and the ERGO M575S, and the older Logitech Unifying receiver with the MX Vertical. Windows desktops and most Windows laptops still carry USB-A ports, so each receiver plugs straight into the machine — no adapter, no hub. The receiver route that costs a MacBook reader an extra purchase is, on a Windows desk, simply the route in the box. For a desktop that lives in one place or a desk where a receiver has proved steadier than Bluetooth, that is the whole setup.

Read the receiver standards honestly, because the box holds two of them. Logi Bolt is not compatible with Logitech Unifying: a Bolt receiver does nothing for the Unifying MX Vertical, and the vertical's receiver does nothing for the three Bolt mice. A desk standardising on one receiver cannot include both families, and a spare from the other standard is not a spare at all — check which standard is already plugged in before assuming the new mouse can share it.

Bluetooth is the fallback everywhere, and one mouse keeps a wired door open. All four mice also pair over Bluetooth Low Energy, for the laptop whose USB-A ports are full or absent, using no port at all. The MX Vertical goes one step further: it also works wired over its included USB-C cable, and it stays usable while it charges — the only wired mode in this guide. No other mouse here has one: the Lift and the ERGO M575S run on AA batteries with nothing to plug in, and the MX Master 3S's recorded connection set is Bluetooth and its Bolt receiver. If a cable fallback matters to your Windows setup, that is a genuine split, not a footnote.

Check two: the Windows version floor — only one pick names one

The version floor splits the four, and it splits them unevenly. The ERGO M575S is the only mouse here whose compatibility names a Windows version: Windows 10 or 11, alongside macOS 12 or later, ChromeOS, Linux, iPadOS 15 or later and Android 12 or later, with basic functions without the app outside Windows and macOS. A machine on an older version is outside that pick as catalogued — the single hard exclusion in this guide. The other three list plain Windows with no version floor recorded — the MX Master 3S, the Lift and the MX Vertical each record “Windows”, and this guide claims nothing more precise than that.

State that asymmetry plainly, because a listing page will not. It is tempting to read the trackball's named floor as a requirement the others secretly share, or their silence as a promise about every Windows version ever shipped. This guide does neither: what is recorded is what is claimed — one pick with a stated Windows 10 or 11 floor, three with no floor recorded. A reader on a current machine clears the one gate that exists; a reader on an older machine should treat the trackball as closed and the other three as recorded — no more, no less.

Check three: the software — Logi Options+ runs in full on Windows

The software layer is where a Windows mouse earns its buttons, and on Windows nothing here is a second-class port. Customisation runs in Logi Options+, and the MX Master 3S's app-specific customisation is recorded as requiring Options+ on Windows or macOS — Windows is one of the two full-software platforms, not a port of the other. The recorded counts are part of the pick: the MX Master 3S customises its 7 buttons alongside a thumb wheel and a gesture button, the Lift and the MX Vertical each customise 4 of 6 buttons, and the ERGO M575S customises 3 of 5 — with the trackball's sensitivity, 400 to 2,000 DPI, set only in Options+, since it carries no DPI button.

Cross-computer control follows the same three-and-one split. Logitech Flow — pointer and copy-paste travelling between computers — is listed for the MX Master 3S, the Lift and the MX Vertical, the same three that switch across up to three devices with Easy-Switch. For a desk running a Windows machine beside another computer, that switching layer is a first-class setup on these three. It is not listed for the ERGO M575S, and neither is Easy-Switch: the trackball connects by its included Bolt receiver or Bluetooth, and this guide claims no multi-device switching for it.

Finally, the version question, stated before a listing page raises it. Logitech sells separate “for Mac” listings — a Lift for Mac and an MX Master for Mac among them. Those are different listings from the standard versions reviewed here, we have not reviewed them, and nothing in this guide carries across to them — they are not the ones to buy for a Windows desk. The standard versions list Windows and serve Windows and mixed desks alike, which the Mac-only variants by design do not offer. The MX Vertical has no “for Mac” variant at all, and the ERGO M575S variants are only colourway and UK listings.

Shape still decides — the Windows layer narrows, the hand chooses

Run the three checks and the field narrows — receivers that plug straight in, one version floor, full software — but nothing in them tells your hand what to hold all day. The MX Master 3S is the sculpted conventional body: palm-down, scroll-heavy, with a sensor that tracks where the others cannot. The Lift stands small-to-medium hands up at 57 degrees. The MX Vertical stands the same angle in a larger body, rechargeable, with the wired fallback. And the ERGO M575S removes movement entirely: the body never travels, your thumb rolls the ball, and the mouse needs only its own footprint. When none of these is the right buy

Handedness limits the whole guide first: all four mice are right-hand in the listings reviewed, with no left-hand version recorded. A left-handed Windows reader is outside what these picks cover. The second limit is the version gate: a machine below Windows 10 still has three picks here, but the trackball is closed to it. And some Windows desks honestly want a pointer built for a different job — a gaming mouse, or a basic wired mouse for a fixed shared machine — categories we have not reviewed, named here as criteria only, with no verdict. Before you buy: the two-minute Windows test

Two minutes at the machine settles which version of this guide you are shopping in. First, the version test: open Settings and read the Windows version. Ten or 11 keeps all four picks open; below it, cross the trackball off early. Second, the port test: count the machine's free USB-A ports. Every receiver here plugs straight into one; a machine with none free makes Bluetooth the route, which all four also offer — and Bolt and Unifying do not share, so name which standard the desk will hold. Third, the hand test: notice the strain, if any — palm-down twist points at the verticals, arm travel points at the trackball, no strain at all points at the sculpted default. Then buy that mouse, and pair it on the day it arrives, inside the return window.

Which mouse is best for a Windows PC?

For most Windows desks, the Logitech MX Master 3S: a sculpted conventional shape, a Darkfield sensor that tracks even on glass, MagSpeed and thumb wheels, up to three devices with Logitech Flow, and a rechargeable battery rated at up to 70 days. They plug straight in. Bottom Line

Run the receiver and the version first — then let the hand choose

Ask first how the mouse reaches the machine — a USB-A receiver that plugs straight in, for all four, with Bluetooth as the fallback and a wired mode on one — then whether the Windows version clears the one floor in the guide. For most desks the answer is the Logitech MX Master 3S: sculpted, glass-tracking, Flow across machines, and the fullest Options+ kit on Windows. Where small-to-medium hands want the 57-degree angle and a two-year AA battery, the Logitech Lift is the pick on the same footing. Where larger hands want that angle with a four-month rechargeable battery and a cable it can work through while charging, the Logitech MX Vertical is the pick — with its Unifying receiver stated plainly.
