Buying Guide — Keyboards

Best Keyboard for a Windows PC

The short answer first: every keyboard we review lists Windows in its compatibility line, so "works with Windows" is not the question — the Windows experience is decided by three quieter checks. The box: three boards include a USB-A receiver that plugs straight into the USB-A ports Windows desktops and most Windows laptops still carry, and the compact one ships without one. The software: Logi Options+ customisation runs in full on Windows, so nothing here is a second-class port. And the legends: all four are dual-labelled for Windows and Mac, so there is no Mac-layout trap to avoid. One board answers all three checks cleanly. One answers them with mechanical switches you feel rather than hear. One answers them with a split frame and a two-year battery. And one answers them in a smaller frame, with the missing receiver as a convenience gap — on Windows, not a login blocker.

Check one: the receiver in the box — and a USB-A port to put it in

Start with what is physically in the box, because on a Windows desk the receiver question is a convenience question with a simple shape. Three of the four boards here include a USB-A receiver: a Logi Bolt receiver in the box with the MX Keys S and with the MX Mechanical, and the older Logitech Unifying receiver in the box with the Ergo K860. Each of those receivers plugs straight into the USB-A ports Windows desktops and most Windows laptops still carry — no adapter hunt, no hub required for the keyboard itself. The fourth board, the MX Keys Mini, includes no receiver at all: it is Bluetooth only out of the box, a Logi Bolt receiver is a separate purchase, and Unifying receivers are not compatible with it at all. Every board here also pairs over Bluetooth LE and switches across up to three devices with Easy-Switch keys, so the receiver is the alternative route, not the only one — but three boards give you both routes on day one, and one gives you Bluetooth alone.

Read that against the Mac version of this guide honestly, because the stakes invert. On a Mac, the receiver earns its place at the login screen: with FileVault enabled, a Bluetooth keyboard may not answer before you have logged in, and the receiver is the documented route through that step. That problem does not arise the same way on Windows, and this guide will not pretend otherwise. On a Windows desk the Mini's missing receiver costs you the plug-in fallback — for a desktop that lives in one place, a shared machine, or a Bluetooth stack that misbehaves — not access to the machine at login. It is a real gap, priced as a separate purchase below; it is simply a smaller gap here than the same box causes on the other platform.

Check two: full software on Windows — nothing here is a second-class port

The customisation layer is where platform guides usually find a catch, and on Windows there is none to find. Full software features on these boards — Logi Options+ backlight control, key remapping and the rest of the customisation layer — are supported on Windows and on macOS. The MX Keys S and the MX Mechanical record the split in their own compatibility lines: Windows, macOS, Chrome OS, Linux, iPadOS and Android, with full software features on Windows and macOS and basic typing without software on the other systems. The Ergo K860's recorded compatibility is Windows, macOS, Chrome OS and Linux, and the Mini's legends and pairing serve the same Windows-first pattern. Judge the check plainly: a Windows buyer gets the complete version of whichever board they choose, and the limited, basic-typing version is the one a Chrome OS, Linux, iPadOS or Android desk gets.

That also settles how to read the one alarming-looking note in this catalog. The MX Mechanical's recorded specifications carry a note that on a FileVault-enabled Mac, Bluetooth may not enter a startup password, with the Bolt receiver named for that step. Frame it exactly as recorded: it is a Mac-specific startup step that simply is not a Windows step, and no Windows equivalent needs planning around. A Windows buyer who meets that note in a listing can set it aside — and can note that this board's Bolt receiver is in the box anyway, so the receiver route exists on the desk whichever platform it serves.

Check three: legends and layout — dual-labelled boards, no trap to avoid

On legends, the four boards tie — honestly, and in the Windows buyer's favour. Every keyboard here labels its key legends for both Windows and Mac: the MX Keys S, the MX Mechanical, the MX Keys Mini and the Ergo K860 alike, the last with its layout and function keys labelled for both systems. No board on this page asks a Windows user to translate a Mac-only legend, guess at a key, or relearn a layout drawn for the other platform. The board that arrives is the board its keys describe, on a Windows machine, on day one.

So the version question answers itself, and it is worth stating before a listing page raises it. Logitech sells separate for Mac versions of these boards, with Mac-only legends, under different listings; those are not the ones to buy for a Windows desk, and we have not reviewed them, so nothing in this guide — no figure, no verdict — carries across to them. The dual-legend versions covered here are the Windows buy: one board, correctly labelled for Windows and for Mac, switching between up to three devices. For a desk that runs a Windows machine beside a Mac, that dual labelling is not a compromise but the point. The Windows pick: Logitech MX Keys S

The MX Keys S is the only board here that passes all three Windows checks with nothing added. Its recorded compatibility covers Windows with full software features, its key legends are labelled for Windows and Mac, and the Logi Bolt USB receiver is in the box, ready for the USB-A port a Windows desktop or laptop still offers — with Bluetooth LE as the second route across up to three Easy-Switch devices. The board itself is the complete full-size package: 104 keys with a numpad in a straight, low-profile frame 16.94 inches wide and 810 g, Perfect Stroke spherically dished scissor keys that centre each fingertip and stay quiet doing it, and a smart white backlight that wakes as your hands approach and adjusts its brightness to the room. It recharges over USB-C and keeps working while it charges.

Fit check: the backlight is a trade with steep terms — rated up to 10 days with it on against up to 5 months with it off, so a reader who leaves the light on should expect the cable roughly weekly and a reader who turns it off can nearly forget it. The frame sits at a fixed angle with no tilt adjustment to raise, and Bolt is not compatible with Unifying, so an older Unifying mouse cannot share this receiver. Inside those lines, it is the complete Windows desk keyboard of the four. Our full review records the whole picture.

When none of these is the right buy

All four keyboards here are wireless, office-shaped boards, and some Windows desks honestly need a different category — named here as criteria only, because we have not reviewed boards in them and will not invent verdicts about them. If your desk needs a keyboard that types over a cable — a wired board, chosen for a fixed desktop that never moves, a shared machine where pairing is a nuisance, or a setup where wireless is not welcome — judge candidates on the cable being the typing connection rather than a charging lead, since none of the four above types over its cable. If your desk is built for play, a gaming board is a different purchase again: judge candidates on the criteria that category is bought on, not on the office checks in this guide. And if swapping switches after purchase is the point, a hot-swappable board is the category to shop — the one mechanical board here is explicitly not hot-swappable. Name the category your desk actually needs before you shop; if it is one of these, no pick above should be forced into the job.

Before you buy: the two-minute Windows test

Two minutes at your own desk tells you which version of this guide you are shopping in. First, the port test: look at the machine the board will serve and count its USB-A ports. A free USB-A port makes any included receiver a plug-in decision; a machine without one makes Bluetooth the route for every board here, which is when the Mini's missing receiver stops mattering and the other boards' receivers become spares in a drawer. Second, the household test: list what else the board must serve — a Mac, another Windows machine, a second system the compatibility lines above cover or exclude. That list, read against the receiver and compatibility lines in the table, usually names the pick by itself. Then buy that board, and on the day it arrives, pair it to every machine it must serve, inside the return window, while the behaviour on your desk is still a fact you can act on.

Windows keyboard questions, answered honestly

Which keyboard is best for a Windows PC?

Of the four keyboards we review, the Logitech MX Keys S. Its recorded compatibility covers Windows with key legends labelled for both Windows and Mac, it includes a Logi Bolt USB receiver in the box that plugs straight into a USB-A port, it recharges over USB-C and keeps working while charging, and its full-size layout with smart backlighting is the most complete Windows desk package here. Its honest cost is the backlight's battery trade: rated up to 10 days with backlighting on, up to 5 months with it off.

Does the MX Keys Mini include a USB receiver?

No. The MX Keys Mini is Bluetooth only in the box — no USB receiver is included, a Logi Bolt receiver is a separate purchase, and Unifying receivers are not compatible with it at all. On Windows that is a convenience gap, not a login blocker: the receiver-at-login problem our Mac guide is built around does not arise the same way here, so a Windows reader who pairs over Bluetooth loses the plug-in alternative, not access to the machine. The other three keyboards in this guide each include a receiver — Logi Bolt on the MX Keys S and the MX Mechanical, Unifying on the Ergo K860.

Do these keyboards get their full software features on Windows?

Yes. Logi Options+ customisation — backlight control and key remapping — is fully supported on Windows and on macOS. Where a board's recorded compatibility lists Chrome OS, Linux, iPadOS or Android beyond those two systems, those systems get basic typing without the software layer. That is the inversion a Windows buyer should notice: on Windows nothing here is a second-class port, while the limited version of these keyboards is the one the other systems get.

Should I buy the 'for Mac' version of one of these keyboards for a Windows PC?

No — the versions reviewed here are the ones to buy for a Windows desk. All four label their key legends for both Windows and Mac, so there is no Mac-layout trap to avoid and no separate Windows version to hunt for. Logitech's separate for Mac versions of these boards are different listings with Mac-only legends; we have not reviewed those listings, and nothing in this guide carries across to them. The dual-legend boards covered here are correctly labelled for a Windows machine on day one.

Does the FileVault note on the MX Mechanical affect a Windows PC?

No. That note in the MX Mechanical's recorded specifications concerns a FileVault-enabled Mac: on that system, Bluetooth may not enter a startup password, and the Bolt receiver is the route named for that step. It is a Mac-specific startup step that simply is not a Windows step, so a Windows buyer does not need to plan around it. The point is moot for this board in any case — its Logi Bolt receiver is included in the box, so the receiver route exists on the desk from day one.

Bottom Line

Run the receiver first — then let the shape choose

Run the checks in order: settle the receiver in the box against the USB-A ports your machine actually has, confirm the full Windows software serves your setup, and take the dual legends as the settled point they are. The complete Windows answer: the Logitech MX Keys S, receiver included, dual-legend, USB-C powered. The feel answer: the Logitech MX Mechanical, a bump you feel rather than hear, with its receiver in the box and its one alarming note belonging to the other platform. The ergonomic answer: the Logitech Ergo K860, split and two-year-batteried, on the older receiver standard. And the compact answer: the Logitech MX Keys Mini, Bluetooth only in the box — a separate receiver to budget for if you want the plug-in route.
